# 成品样例

> 每条含两部分：**A 路径**（走模板链路，只写主体句）与 **B 路径**（裸投喂，写全七段）。
> 直接复制 B 路径即可用；A 路径粘到项目提示词框。

---

## 例 1 · 雪山日照金山（`dramatic` / 极冷极淡）

**A 路径（只写这行）**

```
日出时分的锥形雪峰，云海在山腰缓慢翻涌，峰顶刚被第一缕光照亮【山】
```

**B 路径（完整）**

```
一座锥形雪峰从缓慢翻涌的云海中拔起，峰顶刚被第一缕光照亮，山谷仍沉在冷蓝阴影里。
薄雪被风从山脊上拉出细线，缓慢飘散。
从高处横向极慢滑轨，200mm 长焦压缩，每道山脊之间隔着一层薄雾。
清晨低角度侧逆光，峰顶镶一圈粉金边，山谷冷青，高光受控、天空不过曝。
庄严而安静。电影级调色，细腻胶片颗粒，自然对比。
画面停在峰顶上，随光线缓慢下移，没有新元素进入。
```

**为什么这样写**：主角=锥形雪峰（专名）；光位=低角度侧逆光；冷底暖顶（极冷极淡板 sat 0.24）；两条运动（雪雾飘、镜头横移）但只有一条镜头主轴。

## 例 2 · 沙丘脊线（`cinematic-calm` / 极简）

```
一道弯曲的沙丘脊线斜切过画面，向阳面刻着风纹，背阴面落进深蓝阴影。画面空无一人。
沙粒被风从脊线轻轻扬起，缓慢横移。
静态锁定机位，400mm 长焦压缩。
日落前的极低侧光，亮面暖、暗面冷，明暗交界锋利。
沉默而荒凉。近似单色的影调，只留一个主色，细腻颗粒，高光受控。
画面停在空荡的脊线上，没有脚印，除了沙什么都不动。
```

**为什么这样写**：负空间 60%+；主角是一条脊线不是"沙海"；静态机位避免溢出；1x 式的减法。

## 例 3 · 银河拱桥（`cinematic-calm` / 暗底暖星云）

**A 路径**

```
银河拱桥横跨盐湖，湖面如镜倒映星轨，无月夜【星空】
```

**B 路径**

```
银河拱桥横跨过浅水盐湖，水面几乎无风，把星核完整倒映出来，浅水下隐约可见盐壳多边形。
星点以长曝的感觉缓慢漂移。
膝盖高度极慢推进，14mm 超广，地平线严格水平。
无月夜，东边地平线有微弱黄道光，冷蓝环境里托着暖色星核。
浩瀚而安静。深色底子，星云暖调，品红与青金，自然对比，细腻颗粒。
画面停在镜面倒影上，没有帐篷、没有篝火、没有灯。
```

**注意**：天文题材亮度目标 75–85，比风光片暗一档；`没有帐篷、没有篝火、没有灯` 必须写，否则模型爱加这些。

## 例 4 · 深空星云（天文子类 1）

```
整个画面被一片深空星云填满，电离氢云呈品红与青金，暗尘埃带穿过发光气体，恒星密到能分辨出点。
没有地平线、没有地景，只有望远镜视场。
镜头完全锁定，没有视差，只有气体亮度缓慢起伏。
深色底子配高动态范围，自然对比，细腻颗粒。
画面停在气体上，没有航天器、没有文字，没有新元素进入。
```

**为什么单独成类**：无地景、无焦段概念、色彩是"自发光"而非反射光，和地面风光完全两套语法。

## 例 5 · 秋色峡谷（`dramatic` / 暖浓）

```
深秋的密林峡谷，赭红与锈黄的树冠填满中景，谷底一条细河接住唯一一点冷光。
落叶缓慢从坡上飘下，水面的雾正在升起。
从河面缓慢摇臂升起，35mm，大景深。
午后侧光扫过山脊，暖赭的高光对着冷蓝的阴影。
浓郁而安静。暖调偏浓，赭石与铁锈色，阴影里留冷，电影级调色，细腻颗粒，高光受控。
画面停在树冠上，没有新元素进入。
```

## 反例与改法

### ❌ 失败写法

```
美丽的雪山日落，4K超高清，电影级画质，震撼大气，无人
```

**六个问题**：
1. 无主角（"雪山"不是一个可命名的峰体）
2. 无光位（"日落"没说侧逆光还是正面光）
3. 画质词会被模板**重复追加六次**
4. `无人` 会与结尾留白池重复
5. 无运镜
6. 无高光控制 → 天空必死白

### ✅ 改后

```
日落最后十分钟的锥形雪峰，侧逆光把峰顶边缘烧成金线，山谷沉入冷蓝，
一缕雪雾被风拉出峰脊【山】
```

**改动**：具体峰体 → 明确光位 → 一个自然运动 → 保留尺度线索（雪雾）→ 删掉全部画质词。

## 批量生成时的差异化技巧

同主题连续多段时，`seed` 会轮转运镜，但池子只有 3–4 项，第 4–5 段开始重复。用**主体句差异**承担变化：

| 段 | 主体句差异点 | 运镜 |
|---|---|---|
| 1 | 峰顶（远） | 横移 |
| 2 | 冰川舌（近） | 推进 |
| 3 | 冰碛湖倒影（低） | 静态 |
| 4 | 雪脊风纹（微距） | 长焦压缩 |
| 5 | 云海翻涌（高） | 航拍俯视 |

这样即使运镜池重复，画面也不会重复。
