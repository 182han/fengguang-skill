## 2. 测量方法

- **静帧**：按行内方差（`row_std > 14`）自动定位画面带，排除手机黑边与 UI；取最长连续段。
- **视频帧**：直接取视频快照 sprite（10×10 网格），排除 `mean lum < 12` 的黑格。
- **指标**：
  - `lum` = 0.2126R + 0.7152G + 0.0722B 均值
  - `dark` = 亮度 < 40 的像素占比
  - `hl` = 亮度 > 200 的像素占比
  - `sat` = HSV 式饱和度（(max−min)/max）均值
  - `warm` = R > B+15 且 R > G+10 的占比
  - `cool` = B > R+15 的占比

## 3. 总表：静帧 vs 长片

| 指标 | 80 静帧 mean / median | 2210 长片帧 mean / median |
|---|---|---|
| lum | 104.0 / 102.1 | 105.1 / 103.4 |
| dark | 16.3% / 16.1% | 13.8% / 8.8% |
| **hl** | 7.1% / **3.4%** | 5.8% / **0.2%** |
| sat | **0.405 / 0.386** | **0.339 / 0.317** |
| warm | **27.5% / 19.3%** | **15.1% / 4.9%** |
| cool | 38.7% / 37.6% | 35.0% / 30.4% |
| 暖主导帧 | 40.0% | 31.8% |

**结论**：
1. 亮度几乎一致（104 vs 105）→ 可作为硬指标。
2. 静帧比长片**更浓（sat +0.07）更暖（warm +12pt）** → 这是"比赛级戏剧感"与"长片耐看感"的分界，故设两档。
3. 长片高光中位 **0.2%** → 专业片几乎不允许死白天空。

## 5. 题材结构（来自长片帧）

长片实际包含：雪山、冰川、峡湾、海岸、沙丘、森林、花海微距、野生动物（鲸/猫头鹰/野兔/水鸟）、城堡、葡萄园、铁路、雪原、银河、星云、星轨。

→ 结论：不是"一条地貌拍到底"，而是镜头配比（见 SKILL.md §十）。

**注**：Scenic Relaxation 原片带角标水印（画面内文字），本项目不应复现。

## 6. 画幅事实

- 静帧画面带：**1.50（3:2）占 26/80**，16:9 仅 3 张，2.33 宽银幕 2 张。
- 长片：原生 16:9（3840×2160 / 7680×4320）。

→ 参考图是**摄影静帧**，不是视频帧；改 16:9 必须重排构图（SKILL.md §七 警告）。

## 7. 复现方式

统计脚本依赖：Python 3 + Pillow + numpy。
- 静帧：定位画面带 → 计算六项指标。
- 视频：`https://api.bilibili.com/x/player/videoshot?bvid=<BVID>&cid=<CID>&index=1` 取 sprite，
  封面/元信息走 `https://api.bilibili.com/x/web-interface/view?bvid=<BVID>`。
- 全程只读，不下载完整视频。

## 8. 已知局限

- 1x.com 的图片**未能取得像素**（JS 渲染 + 本机无头浏览器不可用）。
  其视觉语法依据：策展分级结构（获奖/已发布/展览）+ 用户参考图中明显的极简样本。
- 静帧是手机截屏，画面带定位依赖行方差阈值，极少数全黑构图可能被误判。
- `warm/cool` 是粗粒度色相判据，不能替代专业色彩分析。
